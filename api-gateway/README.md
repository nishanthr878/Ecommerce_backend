# api-gateway

API gateway module (Spring Cloud Gateway, WebMVC).

## Status

Scaffolded. `spring.application.name=api-gateway` is set, but routing configuration is not present yet.

## Run

From repo root:

```bash
./gradlew :api-gateway:bootRun
```

## Configuration

- App name: `api-gateway/src/main/resources/application.properties`
- Port: not configured (defaults to 8080 unless changed)
