# cart-service

Cart service module.

## Status

Scaffolded. Only `spring.application.name=cart-service` is configured.

## Run

From repo root:

```bash
./gradlew :cart-service:bootRun
```

## Configuration

- App name: `cart-service/src/main/resources/application.properties`
- Port: not configured (defaults to 8080 unless changed)
