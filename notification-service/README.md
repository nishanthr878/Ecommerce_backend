# notification-service

Notification service module.

## Status

Scaffolded. Only `spring.application.name=notification-service` is configured.

## Run

From repo root:

```bash
./gradlew :notification-service:bootRun
```

## Configuration

- App name: `notification-service/src/main/resources/application.properties`
- Port: not configured (defaults to 8080 unless changed)
