# payment-service

Payment service module.

## Status

Scaffolded. Only `spring.application.name=payment-service` is configured.

## Run

From repo root:

```bash
./gradlew :payment-service:bootRun
```

## Configuration

- App name: `payment-service/src/main/resources/application.properties`
- Port: not configured (defaults to 8080 unless changed)
